# ترجمة الصفحات العامة

لا توجد خطوة بناء. تعدّلون HTML وCSS مباشرةً كالمعتاد.

- `translations.js`: النصوص العربية والإنجليزية في `window.siteTranslations`.
- `i18n.js`: تطبيق النصوص، تبديل `lang` و`dir`، وحفظ اللغة في `localStorage` بالمفتاح `club-language`.
- `main.js`: التفاعلات المشتركة، ومنها القائمة والسلايدر بحسب اتجاه الصفحة.

## إضافة نص أو تعديله

1. أضيفوا مفتاحًا واضحًا في قاموسي `ar` و`en` داخل `translations.js`.
2. اكتبوا النص العربي الافتراضي في HTML، واربطوه بالمفتاح:

```html
<h2 data-i18n="about.goals">أهدافنا الاستراتيجية</h2>
```

عند تعديل النص، حدّثوا العربية في ملف الترجمة وفي HTML، والإنجليزية في ملف الترجمة.
تستخدم العناصر المشتركة مفاتيح `common.*`، وبقية النصوص مفاتيح الصفحة المناسبة.

## الأيقونات والتنسيق الداخلي

لا تضعوا `data-i18n` على عنصر يحتوي أيقونة أو عناصر تريدون الحفاظ عليها؛ التطبيق يستبدل النص بـ `textContent`.
ضعوه على الجزء النصي فقط:

```html
<a href="about/">
  <span data-i18n="common.about">من نحن</span>
  <i data-lucide="arrow-left"></i>
</a>
```

## وصف الصور والحقول

```html
<img src="logo.png" alt="شعار النادي" data-i18n-alt="common.shortLogo">
<input placeholder="النص الافتراضي" data-i18n-placeholder="page.fieldHint">
<button aria-label="الوصف الافتراضي" data-i18n-aria-label="page.buttonLabel"></button>
```

يدعم السكربت أيضًا `data-i18n-title`، وترجمة `<title>` باستخدام `data-i18n`.

## النصوص التي تُنشأ في JavaScript

ضعوا العلامات نفسها على نصوص الواجهة الثابتة، ثم استدعوا:

```js
window.siteI18n?.apply(container);
```

النصوص القادمة من Firebase تبقى بلغتها الأصلية ولا تحتاج مفاتيح ترجمة.
حقول النافذة التي يستبدلها المحتوى تستخدم `data-i18n-preserve-runtime` لمنع إعادة نصوصها الافتراضية عند تبديل اللغة.
في نافذة لقاءات التطوير، ننسخ مفتاح الترجمة من البطاقة للحفاظ على عنوان اللقاء عند التبديل.

عند غياب ترجمة إنجليزية يستخدم السكربت العربية. العربية هي اللغة الافتراضية، ويستمر الموقع بعرضها عند تعطيل JavaScript.
عند حظر التخزين يعمل زر اللغة داخل الصفحة، لكن لا يمكن حفظ الاختيار بين الصفحات.

## ترتيب الملفات في `<head>`

حمّلوا `css/i18n.css` بعد بقية CSS، ثم السكربتين بالترتيب:

```html
<script src="js/translations.js" defer></script>
<script src="js/i18n.js" defer></script>
```

في الصفحات الفرعية تبدأ المسارات بـ `../`.
لتنسيق الاتجاهين استخدموا `text-align: start` و`padding-inline-start` ونظائرها بدل فرض اليمين أو اليسار.
